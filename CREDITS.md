## 🛠️ Specialized Plugins & Engineering Workflows

### 1. Agentic Engineering & Spec Workflows
- **OpenSpec Protocol**: Spec-driven iterative software lifecycle by OpenSpec contributors.
- **TDD Closed-Loop & Worktree Delegation**: Inspired by best practices from the Linux kernel, Git worktree architecture, and modern autonomous agent testing paradigms.

### 2. Developer Power Skills & Modern Web Guidance
- **Vercel Engineering**: React 19 performance guidelines, Next.js architecture, and React composition patterns ([vercel.com](https://vercel.com/)).
- **Cloudflare**: Cloudflare Workers, Durable Objects, and Wrangler CLI ecosystem ([cloudflare.com](https://cloudflare.com/)).
- **LieFlat Charts & Canvas Design**: Visualization patterns powered by Apache ECharts, p5.js, and Chart.js communities.
- **Office Document Processing**: Document, spreadsheet, and presentation manipulators (python-docx, openpyxl, python-pptx, PyPDF).

### 3. Elite Workflows & Taste
- **gstack & Claude Code Community**: Diagnostic and developer velocity skills including `investigate`, `qa`, `ship`, `spec`, `handoff`, `test-audit`, and multidimensional plan reviews.
- **Editorial UI & Brutalist Design**: Typographic hierarchies inspired by Swiss typographic design, Brutalist web aesthetics, and agency-grade design systems.
